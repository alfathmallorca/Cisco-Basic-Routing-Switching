# Basic Routing & Switching Configuration

Proyek ini adalah simulasi jaringan menggunakan Cisco Packet Tracer yang mendemonstrasikan praktik *Basic Configuration* pada perangkat Router dan Switch Cisco.

## 🎯 Tujuan Lab
- Konfigurasi Hostname perangkat (R1 dan SW1).
- Pengamanan akses tingkat lanjut (User Access & Enable Secret).
- Konfigurasi IP Address pada interface fisik (G0/0) dan VLAN.
- Mengaktifkan Remote Access menggunakan protokol SSH dan Telnet.

## 🖥️ Perangkat yang Digunakan
- 1x Cisco Router (R1)
- 1x Cisco Switch (SW1)
- 2x End Devices (PC/Laptop)

## 📝 Skrip Konfigurasi
File teks konfigurasi lengkap (`.txt`), tabel *addressing*, dan file topologi Packet Tracer (`.pkt`) telah dilampirkan pada repositori ini dan siap diunduh untuk pengujian.
